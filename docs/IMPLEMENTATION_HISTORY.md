# 345 导航模块测试

独立 ROS2 包 `starpath_3d_navigation`，在 Ubuntu 24.04 / ROS2 Jazzy 上构建。默认运行新的底盘 SE(2) 动作搜索器；位置、朝向以及直行/弧线/原地转动一起规划。原 SCAN 核心仍保留源码用于对照，但默认启动不再经过位置A*和B样条链路。真机碰撞使用底盘矩形与随朝向旋转的上身部件集合。保留上游 Apache-2.0 LICENSE、NOTICE 及原文件哈希，适配代码在本包维护。未替换原控制中心、VR导航或三维建图包。

## 桌面使用

打开“导航模块测试”。已有 AIRY 三维定位时，直接“连接并启动导航测试”。否则选择完整地图 `manifest.json`，点“启动三维定位”，静止等待锁定，再连接导航测试。地图、实时扫描（紫红）、轨迹（橙色）及机身包络参考框分别显示；视图支持旋转、平移、缩放和俯视选点。

输入目标 X/Y 或点击“在地图选目标”，首先“生成轨迹预览”。“执行此目标（低速）”会重新规划，并在健康条件满足时显式授权执行；启动界面和生成预览均不会自动移动。到点朝向可选。取消目标、空格、Esc、窗口失焦或关闭测试均停止执行，故障恢复后不会自动续走旧目标。

本版是平地、空手且保持已标定前伸姿态的局部导航测试：取消单次目标3米距离限制，有限坐标目标可以接收。每段搜索在当前位置周围3米内进行，远目标通常先生成约1.8米进展的局部段，段末停车后按最新定位和扫描继续规划；这是每段轨迹的计算范围，不是目标距离限制，也不代表已验证远处整条通路。速度上限0.15m/s，角速度0.30rad/s，仅向前行驶并转向，不自动倒车或横移。不包含持物导航、边走边动手臂、跨楼层、楼梯、坑洞识别、完整酒店全局寻路、VR目标接管或前后双雷达融合。

## 适配与保护

- 输入现有 `/airy_fast_lio/Odometry`、`cloud_registered_body`、`global_pose` 和 `backend_status`。要求已存地图定位模式且已锁定；不以新建图模式代替全局定位。
- 配对同时间戳的全局位姿与前端里程计，计算全局校正；再预测当前IMU及底盘位姿。底盘到AIRY雷达外参来自345原厂配置，雷达到IMU外参来自现有AIRY出厂标定。
- 点云转换至 `airy_global`。默认底盘规划器使用当前过滤后扫描的不可变副本和KD树，按照完整部件距离检查碰撞；不是对旧10厘米占据格重复膨胀。搜索完成后用更新一帧扫描重新检查整条路径。保留当前roll/pitch和底盘高度；未知空间、遮挡背后并不因此得到安全证明。
- 全局定位失效/过期、点云或里程计中断、规划器心跳中断、明显重定位校正都会取消目标，作废正在计算的搜索任务。新轨迹携带当前目标编号，迟到旧轨迹不可恢复旧运动。
- 首次轨迹尚未接受时，起点/目标占用或搜索失败最多停车换新扫描复核两次；必须收到新的扫描帧，持续占用仍拒绝。已执行的轨迹遇到障碍、健康失效或用户取消后不会自动恢复。
- 运行器、看门狗、规划器均按ROS域使用固定单实例锁，不因桌面与测试进程的运行目录不同而允许重复启动。
- 独立 `nav_watchdog.py` 复用现有 MotionGate / ChassisControlLease / VelocityRamp。UI和适配器卡顿不应持续刷新底盘速度；未经本会话执行授权不获取底盘控制权。
- 50Hz平滑速度输出；控制器采用已检查的直行/弧线/转动动作前馈与实测位姿反馈；落后时放慢参考进度，偏离超过15厘米或约23度时取消目标。SCAN原Go2开环模拟和实机控制器不安装、不运行。
- 导航数据仅在 `/scan345/` 命名空间；真正速度只由有租约的看门狗向345原厂话题发送。

## 碰撞几何与边界

真机域必须启用 `nav_body_model.py`。从本机原厂 S3 URDF/STL 和实际双臂、腰腿、颈部反馈计算外形；不默认把未收到的关节设为零。模型文件留在机器人，不复制到本包。

- 自体过滤：已知刚体使用真实网格表面附近12mm带宽，保留两臂之间、外侧及模型空隙内的环境点，不使用覆盖前方的大裁剪盒。
- DM夹爪限制：原厂通用URDF尚无可核实的DM手指开口关系，反馈的约180°不是URDF手指角。2026-10-20经用户确认空手且夹爪周围20cm净空后，采集60帧静态数据建立表面模板，候选点须被至少3帧重复观测。直接自体过滤只屏蔽距稳定表面20mm以内的回波；另对射线先穿过已确认夹爪表面的点做遮挡检查（至少3个表面支持点、6mm射线带宽、回波在表面后方至少20mm）。移除整条遮挡射线，不发送远处自由端点。模板存在 `~/.config/starpath_3d_navigation/empty_gripper_profile.npz`，不是完整CAD模型。
- 模板绑定本机URDF、AIRY外参、全部身体/双臂/颈部姿态和夹爪开口。关节偏离0.75°或夹爪反馈偏离3°即失效；变化/通信丢失会取消目标，恢复后不会自动续走。更换夹爪、夹持物品、形状变化需要重新适配，不能沿用此模板。
- 时间约束：检查厂家JSON时间戳持续推进和接收间隔，同时缓存接收时刻的关节样本，对每帧扫描插值；最大缺口60ms、边缘容差30ms。厂家时间戳与系统时间有未核实的偏移，因此**不是硬件同步或逐点去畸变方案**，继续强制关节静止窗口和固定姿态，不支持运动机械臂。
- 避障：底盘轮廓前0.34m、后0.30m、左右0.25m，外扩40mm；绿色框显示这部分。上身按实际FK位置的各刚体包围盒加40mm余量独立检查；未知夹爪仍使用以各自手腕为中心的保守运动链范围。蓝灰线显示上身部件。侧面空隙和不与部件相交的高处物体，不再被底盘中心的大圆误挡。实际会碰到手臂、躯干的桌面/横梁仍保留。
- 外形变化时取消当前目标并确认新几何，确认前不能规划/执行。内部协议为`[revision, kind,cx,cy,cz,hx,hy,hz, ...]`，kind=0为底盘系盒、1为球；几何在静止姿态窗口内只扩不缩，避免关节噪声反复重置。
- 默认规划器按每2厘米平移/1度旋转采样每个候选动作；按当前三维姿态检查各部件与原始过滤后点云的距离，额外保留2厘米停止间距。不同朝向作为不同搜索状态，原地转不通时可以搜索先直行或向另一侧转弯的路线。加权A*有3.5秒预算，不保证全局最优或在任意复杂障碍中都找到路径。
- 近目标先检查可停放朝向，并将可行接近方向用于搜索引导。未指定终点朝向时按2度采样，同时用部件最大转动位移界限补偿采样间隙，只有能排除采样间隙中的可行姿态才报告“目标点没有停放朝向”；不会仅因离散采样失败就判死。
- 新轨迹协议 `ChassisPath` 同时携带起终位姿、线速度、角速度、持续时间和目标编号；接收端验证动力学连续性、起点偏差≤8厘米/约5.7度、原终点不变、最新点云下起步段可行。执行时按实际弧线检查未来0.5秒扫掠范围，不再使用“先转向前视点”的替代动作。
- 当前净距数值相对于已加余量的部件，超过0.30m时截为0.30m；它不是裸机外壳的测量距离。
- 底盘矩形的垂直范围来自原厂`Link_Zero_Point`网格，额外加40mm；不再固定拉伸到0.40m。345当前模型加余量后的顶部约0.37m，避免把底盘上方空间错误计入低层轮廓。
- 取消、输入失效或新目标使工作线程旧结果作废；ROS主线程持续处理心跳和急停。远目标不再沿直线参考路径偷偷缩短；近目标必须到达原坐标，指定朝向也须满足。局部段末停车后继续规划，暂不支持不停顿跨段拼接。
- 规划器通过携带目标编号的`planning_error`反馈参考路径失败、局部搜索失败或轨迹碰撞；运行器只处理当前目标的错误，迟到旧错误不得取消新目标。界面换行显示并记录失败原因，不把所有失败都显示成等待8秒后的规划超时。
- 平地轨迹使用当前底盘地图高度，允许地图Z为负值；规划失败区分起点间隙不足、输入过期、搜索预算用尽、无可行底盘路线和最新点云碰撞。

需要完整的任意姿态长期方案时，应补齐真实DM夹爪CAD/尺寸、开口标定和可信的硬件时间映射，统一模型自体过滤与碰撞检测。当前版本只能作为固定空手前伸姿态的受限测试，不能宣称已完成上述任意姿态适配。

距底盘参考平面0.08m以下的回波作为地面候选排除，因此不能用于低矮障碍/台阶/坑洞的完整安全判断。当前仅使用前置AIRY观测，后方遮挡未通过后置2D补足。测试环境应为已确认的平整通道，保留现场急停。

三维地图PCD仅作为定位/显示参考；实时避障使用过滤后实时扫描；默认底盘搜索器不融合旧体素占据概率。地图坐标校正超过0.25m或10°会作废搜索任务并取消目标；重新锁定后需重新下发。

## 启动

```bash
source ~/ros2_ws/bin/environment345.sh
ros2 run starpath_3d_navigation nav_ui.py
# 命令行默认只允许规划，无硬件速度发布器：
ros2 launch starpath_3d_navigation test.launch.py session:=my_test
```

运行器参数在 `config/robot.yaml`。`config/planner.yaml` 仅供保留的旧SCAN规划器对照；默认底盘搜索的步长、速度和预算在 `include/chassis_search.h`，当前按受限测试值编译，不应只改运行器速度而不核对跟随器。配置改动需要同步检查碰撞模型、点云过滤及速度限制。日志在 `~/ros2_ws/logs/starpath_3d_navigation`；本导航包不保存或改写已有地图。
